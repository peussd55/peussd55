## 박은수 · AI 엔지니어

검색엔진 엔지니어로 시작해 인텐트 챗봇을 거쳐 LLM 에이전트 개발 중.

- **하는 일**: AI 컨택센터 솔루션 회사에서 실시간 AI 콜봇 · 챗봇과 에이전트 개발 · 운영.
- **일하는 방식**: 측정 먼저, 측정값으로 결정. 평가셋과 기준선을 만든 뒤 수정. 구현은 코딩 에이전트와 함께, 설계 · 검증 · 운영은 직접.
- **주무기**: 검색과 RAG. 검색 품질 측정 · 개선에서 출발해 에이전트로 확장.

### 주요 업무

- **실시간 음성 에이전트**: 음성인식(STT) · LLM · 음성합성(TTS)을 잇는 실시간 파이프라인, 의료 도메인 콜봇 실서비스 운영
- **RAG와 에이전트**: 평가셋으로 검색 품질을 재고 개선, 대화 흐름은 코드가 관리하고 LLM은 답변만 맡는 구조, 되돌릴 수 없는 작업 앞의 사람 승인 게이트
- **LLM 서빙과 평가**: 온프레미스 LLM 서빙, 성능 벤치마크, 모델 비교 평가
- **사내 AX**: LLM 게이트웨이와 사내 AI 채팅 도구 도입 · 운영(팀별 예산과 모델 정책 관리), 한도 · 모델 요청을 처리하는 운영 포털 개발
