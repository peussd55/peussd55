## 박은수 · AI 엔지니어

검색엔진 엔지니어로 시작해 인텐트 챗봇을 거쳐 LLM 에이전트를 만들고 있습니다.

- **하는 일**: AI 컨택센터 솔루션 회사에서 실시간 AI 콜봇 · 챗봇과 에이전트를 개발하고 운영합니다.
- **일하는 방식**: 먼저 재고, 잰 값으로 결정합니다. 평가셋과 기준선을 만든 뒤에 고칩니다.
- **주무기**: 검색과 RAG. 검색 품질을 재고 고치는 일에서 출발해 에이전트로 넓혀 왔습니다.
